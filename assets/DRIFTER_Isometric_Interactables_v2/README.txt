DRIFTER — Isometric Interactable Props v2

16 rebuilt interactable props with a consistent 3/4 isometric presentation.
Includes individual RGBA PNGs, a 4x4 atlas, and interaction_manifest.json.

Art direction:
- Same isometric ground-plane orientation across objects.
- Visible top and front/side faces where appropriate.
- Consistent upper-left lighting and contact grounding.
- Transparent backgrounds; equal 192x192 atlas cells.
- Pixel-art nearest-neighbour scaling.

Gameplay metadata is a suggested design layer only; no interaction code is included.
The source atlas was segmented and background-keyed; inspect alpha edges and individual crops before final production integration.
