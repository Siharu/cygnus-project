DRIFTER — POI ASSET LIBRARY v2.0
=================================

SOURCE MATERIAL
- DRIFTER_Ruined_City_Buildings_Pack_v1.zip
- Uploaded “DRIFTER — Relay Station 7” image, used as a STYLE REFERENCE only.

WHAT IS INCLUDED
- Individually extracted transparent PNGs from the supplied RGBA master sheet A.
- Three aligned transparent sprite atlases.
- Permanent POI-01 through POI-16 folder structure.
- POI_Registry.json with source bounding boxes, dimensions, atlas cells and POI mapping.
- Original source sheets retained for traceability.

IMPORTANT SCOPE / HONEST PRODUCTION STATUS
The supplied source ZIP is a generic ruined-city building/props pack. It does not
contain the lost 16 POI-specific building references. No hospital, police station,
fire station, school, shopping mall, bank, library, museum, power plant,
electrical substation, prison or military base assets are claimed as completed.

POI-07 Warehouse and POI-12 Factory contain only generic industrial candidates
from the source sheet. These are not confirmed bespoke warehouse/factory designs.
All other POI folders exist with Exterior/Interior/Props subfolders and are
intentionally empty pending matching references.

STYLE REFERENCE
The Relay Station 7 image establishes the desired 2D-HD pixel-art treatment:
muted post-apocalyptic colours, detailed clusters, deliberate dark outlines,
readable silhouettes, grounded lighting/shadows and varied viewing angles.
It is not used as a source for the missing POI buildings.

EXTRACTION / ATLAS DETAILS
- Individual_PNGs: SRC-001 onward; extracted from Ruined_City_Master_Sheet_A.png.
- Source RGBA alpha is retained and isolated per connected sprite component.
- Transparent pixels are cleared to zero alpha/RGB to avoid checkerboard or
  background remnants from the presentation sheets.
- Combined_Atlases: 4 columns x 8 rows per page.
- Cell size: 288 x 288 px; transparent inner inset: 12 px.
- Sprites are centered in cells, aspect ratio preserved, never stretched.
- Atlas-fit downscaling is used only if a source sprite exceeds the cell area.
- Original camera orientation and pixel detail are preserved from the source.
- Master Sheet B and the style reference are included for traceability only;
  they are not used for cutout extraction because they have presentation
  backgrounds.

LIMITATIONS
- No interiors were present in the supplied files.
- No matched front/right/back/left directional sets were present.
- Some source assets are small and inherit the original sheet resolution.
- Connected components may include attached architectural elements that
  visually form one source sprite.

NEXT STEP
Upload the original POI reference sheets/images if recovered. The remaining
POI-specific assets can then be cut out and added without replacing or
misrepresenting the generic source assets already extracted.
