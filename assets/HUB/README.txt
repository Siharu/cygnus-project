DRIFTER — COMPLETE ASSET BUNDLE
================================

This bundle consolidates the completed DRIFTER location assets, checkpoint gate
states, the fence-sheet generations produced so far, and the available style
reference images.

CONTENTS
--------
01_HUB_Archives/
  Drifter_HUB_assets_Updated.zip  Current consolidated HUB archive.
  Drifter_HUB_assets_Original.zip Earlier HUB archive, retained for history.

02_Standalone_Location_Packs/
  Watchtower/          Individual PNGs, atlases, manifest, README, ZIP.
  Checkpoint_Booth/    Individual PNGs, atlases, manifest, README, ZIP.
  Collapsed_Building/  Individual PNGs, atlases, manifest, README, ZIP.

03_Checkpoint_Gate/
  Corrected_Crosswise/ Preferred gate geometry: barrier crosses the lane.
  Earlier_Iteration_Superseded/ Earlier gate orientation, kept only for history.

04_Fence_Sheets_Work_In_Progress/
  Two generated fence-sheet drafts are included as previews/source renders.
  IMPORTANT: these are combined draft sheets, not three finalized, separated
  atlases matching every requested grid. The third dedicated "Fence Variants
  and Gates" sheet was not generated yet. Do not treat this folder as a final,
  game-ready fence asset set.

05_Style_References/
  Operators_Cottage_Props.png and Operators_Cottage_Shell.png are retained as
  the visual reference sheets used earlier in the DRIFTER asset workflow.

USE NOTES
---------
- For the latest checkpoint barrier geometry, use the PNGs in
  03_Checkpoint_Gate/Corrected_Crosswise/.
- The archive in 01_HUB_Archives/Drifter_HUB_assets_Updated.zip contains the
  HUB locations: Maintenance Depot, Utility Shed, Water Tower Pump Room,
  Watchtower, Checkpoint Booth, and Collapsed Building.
- Standalone packs are also provided so individual location assets are easy to
  access without extracting the HUB archive.
- The earlier gate pair is retained for traceability and is superseded by the
  corrected crosswise pair.
